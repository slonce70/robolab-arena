# RoboLab Arena

**RoboLab Arena** — яскрава браузерна 3D-гра про маленького робота Бліца, який проходить серію арен, збирає шестерні, ухиляється від лазерів, активує кнопки, знищує ворогів і добирається до виходу.

Гра працює прямо в браузері та не потребує бекенду.

## Грати онлайн

[Відкрити RoboLab Arena](https://slonce70.github.io/robolab-arena/)

## Що є в грі

- 12 великих кімнат-арен з різними цілями.
- Вороги кількох типів: дрони, турелі, жуки, щитові роботи.
- Мішені, двері, кнопки, лазерні пастки та фінальні випробування.
- Апгрейди: ремонт, щит, швидка стрільба та надзаряд.
- Перемикання камери між видом від 3-ї та 1-ї особи.
- Збір шестерень, очки, статистика забігу та фінальний екран перемоги.
- Український інтерфейс, підказки та тексти рівнів.
- Автоматичне збереження налаштувань складності, звуку та чутливості.

## Керування

| Дія | Клавіші |
| --- | --- |
| Рух | `WASD` |
| Приціл | мишка |
| Постріл | ліва кнопка миші |
| Стрибок / взаємодія | `Space` або `E` |
| Ривок | `Shift` |
| Перемкнути камеру | `C` |
| Перезапуск | `R` |
| Звук | `M` |
| Пауза / курсор | `Esc` |

## Технології

- [Vite](https://vite.dev/) — збірка та dev server.
- [TypeScript](https://www.typescriptlang.org/) — типізація і логіка гри.
- [Three.js](https://threejs.org/) — 3D-сцена, камера, світло та об'єкти.
- [Vitest](https://vitest.dev/) — автоматичні тести.
- [GitHub Pages](https://pages.github.com/) — безкоштовний хостинг.

## Запуск локально

Потрібен Node.js 22 або сумісна актуальна версія Node.js.

```bash
npm install
npm run dev
```

Після запуску Vite покаже локальну адресу, зазвичай `http://localhost:5173/`.

## Скрипти

```bash
npm run dev
```

Запускає локальний dev server.

```bash
npm test
```

Запускає всі автоматичні тести.

```bash
npm run build
```

Перевіряє TypeScript і збирає production-версію в `dist/`.

```bash
npm run preview
```

Локально відкриває вже зібрану production-версію.

## Структура проєкту

```text
src/
  game/                 логіка гри, рівні, баланс, бойова система, UI-стани
  game/camera/          контролер камери
  main.ts               точка входу
  styles.css            стилі інтерфейсу
public/
  favicon.svg           іконка сайту
.github/workflows/
  deploy-pages.yml      автоматичний деплой на GitHub Pages
```

## Деплой

Деплой налаштований через GitHub Actions. Кожен push у `main` запускає:

1. встановлення залежностей через `npm ci`;
2. production build через `npm run build`;
3. публікацію папки `dist/` на GitHub Pages.

Vite налаштований з `base: '/robolab-arena/'`, щоб assets коректно відкривались на GitHub Pages за адресою репозиторію.

## Якість

У проєкті є набір тестів для балансу, рівнів, бойової логіки, UI-підказок, зіткнень, лазерів, босів, збереження налаштувань та фінальних сценаріїв.

Перед публікацією варто запускати:

```bash
npm test
npm run build
```
